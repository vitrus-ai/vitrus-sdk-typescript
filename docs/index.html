01 · QUICKSTART

Install, configure, connect.

Use the droid serial or display name. The Bridge resolves the identity and keeps device credentials out of your client.

03 · HOW IT CONNECTS

Simple from the client side.

Web clients use the authenticated Bridge. Python clients on the same LAN can bootstrap with the Bridge and then subscribe directly to Zenoh. Camera video uses WebRTC; it is not sent through the telemetry topic.

04 · TYPESCRIPT

Same API, different routes.

client.tsWeb / Node / Bun
import Vitrus from "vitrus";

const droid = await Vitrus.Droid.connect(
  process.env.VITRUS_DROID!,
  { apiKey: process.env.VITRUS_API_KEY! },
);

const state = await droid.telemetry.snapshot();
const frame = await droid.camera.getFrame("head_camera");
05 · PYTHON

Native Zenoh on the edge.

client.pyRaspberry Pi / Linux
from vitrus import Droid

droid = await Droid.from_env()
lease = await droid.acquire(owner="edge-control")
await droid.send_targets(
    [{"joint_name": "NECK_HEAD", "position_deg": 5}],
    lease["id"],
)
